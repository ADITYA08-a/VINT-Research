# ViNT Research: Student Distillation and Traversability

This repository contains a review copy of selected ViNT research code.

## Areas
- `source_snapshot/`: selected source files preserved under their original paths.
- `distillation/`: destination for organized student models, training, evaluation, and benchmarking code.
- `traversability/`: destination for organized traversability code.
- `configs/`: configuration files.
- `results/`: non-weight evaluation metrics and visualizations.
- `docs/`: project reports and documentation.
- `tests/`: tests to add or migrate.
- `scripts/`: reproducible experiment commands.

## Notes
The source snapshot is retained so files can be audited before code is reorganized.
Model checkpoints, datasets, caches, and virtual environments are not included.
Verify licensing, dependencies, data permissions, and reproducibility before publishing.
